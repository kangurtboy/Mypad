# Keyboard Shortcuts

Initial proposed defaults:

| Shortcut | Action |
|---|---|
| Ctrl+N | New tab |
| Ctrl+Shift+N | New window |
| Ctrl+O | Open |
| Ctrl+S | Save |
| Ctrl+Shift+S | Save As |
| Ctrl+W | Close tab |
| Ctrl+Tab | Next tab |
| Ctrl+Shift+Tab | Previous tab |
| Ctrl+F | Find |
| Ctrl+H | Replace |
| Ctrl+G | Go to line |
| Ctrl+A | Select all |
| Ctrl+Z | Undo |
| Ctrl+Y | Redo |
| Ctrl+C | Copy |
| Ctrl+V | Paste |
| Ctrl+X | Cut |
| Ctrl++ | Zoom in |
| Ctrl+- | Zoom out |
| Ctrl+0 | Reset zoom |
| F11 | Full screen |

Implementation must verify key gesture behavior on the selected WinUI controls and avoid conflicts with text input, accessibility, or OS shortcuts.
